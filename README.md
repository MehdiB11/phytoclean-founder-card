# PhytoClean Founder Card

A responsive digital business card introducing PhytoClean and its founder.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

Expected URL: https://mehdib11.github.io/phytoclean-founder-card/

## Personalise the images

The current page includes a designed initials placeholder and a CSS product illustration. Replace them with the supplied founder portrait and PhytoClean product image when the image assets are added to the repository.

Suggested asset paths:
- assets/founder-portrait.jpeg
- assets/phytoclean-products.png
